PokéAPI Developer Documentation

App Interface | API Documentation

1. GET /api/pokemon

Supported Methods: GET, HEAD

Query Parameters:

  • type (string, optional) - Filter Pokémon by type (e.g., "Fire").
  • weakness (string, optional) - Filter Pokémon by weakness (e.g., "Water").
  • limit (number, optional) - Limit max result count (e.g., 5).

Returns: JSON object containing count and matching Pokémon array.

Example Usage: GET /api/pokemon?type=Fire&limit=2

2. GET /api/pokemon/by-id

Supported Methods: GET, HEAD

Query Parameters:

  • id (number, required) - Numeric ID of Pokémon.

Returns: JSON object containing Pokémon data or 404 error if not found.

Example Usage: GET /api/pokemon/by-id?id=25

3. GET /api/pokemon/random

Supported Methods: GET, HEAD

Query Parameters: None

Returns: Single random Pokémon record.

Example Usage: GET /api/pokemon/random

4. GET /api/types

Supported Methods: GET, HEAD

Query Parameters: None

Returns: List of distinct Pokémon types present in the dataset.

Example Usage: GET /api/types

5. POST /api/add-pokemon

Supported Methods: POST

Accepted Formats: application/json, application/x-www-form-urlencoded

Body Parameters:

  • name (string, required) - Name of new Pokémon.
  • type (string, required) - Type(s), comma-separated.
  • height (string, optional) - Height measurement.
  • weight (string, optional) - Weight measurement.

Returns: Status 201 with newly created Pokémon data.

6. POST /api/update-pokemon

Supported Methods: POST

Accepted Formats: application/json, application/x-www-form-urlencoded

Body Parameters:

  • id (number, required) - Target Pokémon ID.
  • name (string, optional) - Updated name.
  • height (string, optional) - Updated height.
  • weight (string, optional) - Updated weight.

Returns: Status 204 No Content on success.
